# Acceptance-From-Pre-sale - scored rubric (copilot-derived)

Derived from PMO Confluence page 3285712947, which is titled "[DRAFT] Checklist: Acceptance From Pre-sale". The A01 standard cites a "v2" of this checklist; no v2 page is findable. So this is OUR scored rubric based on the draft, not an official v2 - say that if a PM or Sales asks where it came from. This is the rubric the A01 handover checklist is scored against. Each item below carries two flags the scorer uses:

- `core` - counts toward the Handover Maturity Index denominator. Nice-to-have items do NOT (they are tracked but excluded from the headline metric).
- `critical` - a `missing` status on a critical item is a MATERIAL gap and counts toward the Critical Uncertainty Ratio.

Conditional items ("if applicable") may be marked `na` with a reason; `na` items drop out of the denominator (they are not "relevant" for this project).

## Project artifacts (all core)

| Item | core | critical |
|---|---|---|
| Project contract + addendums (signed or in signing) | yes | yes |
| WBS | yes | yes |
| Pre-sale requirements (specs, Q&A, designs, source, docs) | yes | yes |
