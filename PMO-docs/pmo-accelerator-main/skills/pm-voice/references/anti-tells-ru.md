# Russian anti-tells

Scan a Russian draft against this list AFTER the length is right. Russian AI text gives itself away
differently from English, so the English list does not cover it. This file is in Cyrillic on
purpose: the patterns are phrases, and a transliterated phrase list does not match the text it is
meant to catch.

## Phrase templates - drop outright

| Phrase | Instead |
|---|---|
| "Важно отметить, что...", "Важно понять, что..." | Сказать сам пункт |
| "Стоит отметить...", "Следует отметить...", "Следует учитывать..." | Сказать сам пункт |
| "В заключение...", "Подводя итог...", "По итогу...", "Таким образом..." в конце | Закончить следующим шагом, или просто закончить |
| "На самом деле..." как вводное | Убрать |
| "Безусловно...", "Несомненно..." | Убрать |
| "Не просто X, а Y", "Это не только X, но и Y" | Калька с английского. Сказать прямо |
| "Уважаемые коллеги", "Доводим до Вашего сведения" | "Коллеги, привет" / "Коллеги, добрый день!" или просто @упоминание |
| "В современном мире...", "В эпоху цифровизации..." | Убрать целиком |
| "С уважением," + полное имя в чате | В чате никто не подписывается. "Спасибо!" или ничего |

## Structure and orthography

| Pattern | Why it reads as AI | What a PM writes |
|---|---|---|
| Заглавная буква после двоеточия | Правило - строчная, модель ставит заглавную по умолчанию | Строчная после `:` |
| Отглагольное существительное в начале ("Использование...", "Применение...") | Любимая конструкция модели | Начать с подлежащего или глагола |
| Цепочка причастных оборотов ("Реализованная стратегия, направленная на..., позволяющая...") | Никто так не печатает в чат | Разбить на предложения |
| Два деепричастных оборота подряд ("Учитывая вышесказанное и принимая во внимание...") | То же | Одно "учитывая что" - нормально, два - уже заметно |
| Нагромождение связок ("таким образом, следовательно, в результате") | Канцелярит | Одна связка или ни одной |
| Числа словами ("три воркшопа", "двести пятьдесят часов") | Модель нормализует | Цифрами: "3 воркшопа", "около 250 часов" |
| Длинное тире | Модель ставит его везде | " - " с пробелами |
| Ёлочки и типографские кавычки | Дефолт модели | Прямые кавычки |
| Последовательное "ё" по всему тексту | Большинство печатает "е" | Как пишется, так и оставить |
| Одинаковая длина всех предложений и абзацев | Низкая вариативность, тот же сигнал, что в английском | Одно длинное, одно короткое |
| Идеальная симметрия "с одной стороны / с другой стороны" | Артефакт генерации | Коротко признать, потом возражать подробно |

## The house lexicon - never translate it

English-in-Cyrillic is how the whole division writes, at every level. It is not slang to clean up:
translating it is what makes a draft sound foreign.

апдейт, эстимейт, реэстимейт, дискавери, воркшоп, фичи, фидбэк, скоуп, деливери, стаффинг, пейды,
апсейлы, онбординг, релиз, билд, дейли, ретро, рефайнмент, спринт, сторипоинты, лэндинг, пресейл.

Abbreviations stay in Latin: PM, QA, BA, TL, BE, FE, DevOps, WBS, PoC, FYI, CR, SOW.

| Not this | This |
|---|---|
| обновление, оценка, обратная связь, объём работ | апдейт, эстимейт, фидбэк, скоуп |
| ПМ, КуА, ДевОпс | PM, QA, DevOps |
| "локализовал корневую причину" | "нашел причину", "разобрался в чем дело" |
| "большой пласт багов" | "много багов" |
| "это может негативно сказаться на..." | "это будет фейл", "иначе X сломается" |
| "выполняет функцию контроля качества" | конкретный образ того, что оно делает |
| "Коллеги, прошу выразить ваше мнение по данному вопросу" | "@Имя @Имя что думаете?" |
| "представляется маловероятным, что данное обстоятельство окажет влияние" | "не думаю что станет проблемой" |
| "Спасибо! Отличное предложение, но..." перед отказом | "Запрос понятный, но есть возражения" |
| "2 b.d." в чате | "2 дня" |

## How the channels read

- `Привет!` или `Привет,` - только в первом сообщении треда. На ответах ничего. Подписей нет.
- Закрывающая `)` для смягчения - норма по всей компании, от руководителей до PM. `))` - когда
  действительно смешно.
- Структура - `1) 2) 3)`, не маркдаун-списки. Жирный шрифт - только у ботов.
- Сокращения без церемоний: `в кот.`, `тк`, `те`, `->` вместо стрелки.
- `СС: @Имя` в конце рассылки.
- `Субъективный пункт -` перед самым слабым пунктом в списке аргументов.
- `Стратегия:` или `Дальше:` - закрывающая метка, что будет дальше.
- Хеджи живые и частые: `вроде`, `думаю`, `по идее`, `насколько я знаю`, `кажется`. Текст без
  единого хеджа в этих каналах выглядит сгенерированным.
- Опечатки остаются, на любом уровне. Никто не переотправляет ради исправления. Не исправлять чужие,
  не выдумывать новые.
- Даты как в чате: `14.09`, `в пятницу`, `вчера`, а не `14.09.2026`.
- Имена как в чате: короткая форма или @упоминание, а не полное официальное.
- Пустой раздел шаблона - `нет` или строки нет вовсе, а не `-`.

**Не полировать сильнее, чем канал.** Там, где никто не вычитывает, вычитанность и есть признак.

## When to switch to formal Russian

Официальные письма в госорганы, HR-документы, договорная переписка, клиенты из консервативных
отраслей, которые сами пишут формально. Там нужен нейтральный деловой русский - это костюм, а не
голос. Бюджет длины все равно действует.
