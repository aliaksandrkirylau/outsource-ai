# TRM-005 Project (well job)

## Definition

In the product, a "project" is one well job at a [[TRM-004 Rig]]: the unit that measurements, inventory
and reports belong to. The first call: "Projects module: create a project (add id, basic details,
location, info on client, order details, quality requirements, etc), edit, remove, assign responsible"
([[2025-10-22 First call with OES - notes]] key point 5). The BA draft: "create a new (or select and
update an existing) well/project entry and input the required details (location, client info, etc.)
with project assigned active status and ID as a result" ([[2025-10-28 BA draft WBS - rendering]] row
13).

## Context and units

- Lasts about as long as drilling the well: "Well drilling duration is about 2 month avg" (notes, key
  point 5). In the client's words on the call: "each well can take between 30 to 45, sometimes 60 or
  more days" ([[2025-10-22 First call with OES - transcript]] 0:12:27).
- The client confirms the unit: the rig's computer "may drill maybe 10 walls, maybe five walls" over
  six months, and "Each of those walls on in themselves is like a project" (1:06:48; "walls" is
  "wells").
- The client's daily report header carries the job's identity: Job#, Operator, Contractor, Rig Number,
  Well Name, Spud Date, Field/Block Num ([[2025-10-29 Client sample daily report - rendering]] rows 3
  to 6).
- A project is divided into [[TRM-006 Well section]]s for reporting.
