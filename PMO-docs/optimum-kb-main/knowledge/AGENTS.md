# knowledge/

- What: the typed notes, one folder per type. Read schema/types.md before writing here.
- Trust: by status. stable = confirmed by the person in verified_by. proposed = waiting for confirmation. draft = unreviewed, often agent-written. disputed = two versions, undecided. deprecated = history, see superseded_by.
- Not for: status, assignees, sprints or hours (Jira, as a generated snapshot at most), blockers (the PMO issue log), money amounts. Risks live here; the filed PMO register is generated from them.
- Autoload: yes.
