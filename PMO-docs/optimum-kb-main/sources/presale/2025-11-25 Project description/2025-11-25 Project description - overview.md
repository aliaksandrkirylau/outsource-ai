## What it is

A one-page project description: purpose, the two components (a native Windows desktop application
on site, a web application for managers, supervisors and admins), the reason for the split, and a
tentative tech stack. Whether it was sent to the client is not recorded.

## How far to trust it

Medium (`sources/presale/`). The two-component shape matches the later SOW v10.4. The stack is
superseded: the desktop client is Flutter now, and the backend is open in DEC-004.

## Not for

The technology choice.

## Removed at ingest

Nothing.

## Summary

The platform replaces Excel-based, largely manual work in drilling fluid operations. The desktop app
is the engineers' offline tool for data entry, calculations, inventory and reports; the web app gives
managers central data, reporting and dashboards. Stack at the time: .NET or Java backend, MAUI,
ReactJS, SQLite on site, PostgreSQL centrally, ASP.NET Identity or Keycloak.
