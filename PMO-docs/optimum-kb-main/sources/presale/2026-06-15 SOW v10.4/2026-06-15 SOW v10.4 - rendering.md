Project Description

The Project focuses on developing a software platform to digitize and automate routine tasks in drilling fluids operations.

Technically, the solution consists of two components: a native on-site Windows desktop application and a web-based system.

The desktop application functions as a mud engineering tool designed to operate even without a stable internet connection.

The web application provides a browser-based interface for managers, supervisors, and administrators, offering high-level project oversight, simplified reporting, and enhanced visibility through a centralized dashboard.

<!-- row 7 -->
The Project Scope Desktop Application includes the following modules:

Login/Logout: Secure user data protection and authorized access to the application.

Dashboard: Clear overview of key information, enhancing usability and decision-making.

Project Management: General project information with support for entering measured data.

Calculations & Modeling: Enables engineering calculations with input variables, automatic computation of derived values, and data visualization using charts and graphs.

Inventory Management: Recording material usage and key inventory events.

Reporting: Generating end-of-day, end-of-section, end-of-well, and inventory reports for comprehensive operational tracking and analysis.

<!-- row 8 -->
The Web Application includes the following modules:

Login/Logout: Secure user data protection and authorized access.

Administration Panel: Full lifecycle management of user accounts, including role assignments, maintaining an audit trail.

Dashboard: High-level one-page overview of operational status, KPIs, and progress across multiple platform sites.

Project Management: Full project lifecycle management, including project setup and editing, assigning/reassigning engineers, viewing project lists and details.

Inventory Management: Handling materials/chemicals and tracking consumption entries.

Reporting: Viewing and exporting generated reports associated with specific projects.

Project implementation phases:

The Project is executed in two main phases: Discovery Phase followed by Development Phase. For delivery and project management purposes, these two phases are further divided into six (6) sequential Milestones.

The Discovery Phase: focuses on understanding business objectives, gathering and clarifying initial requirements, validating assumptions, evaluating risks, and identifying the optimal technical and architectural approach for the solution. The output of the Discovery Phase is a sufficiently detailed scope definition, architecture vision, design concepts, backlog structure, and requirements set necessary to initiate the Development Phase.

The Development Phase: consists of the subsequent implementation Milestones covering design, development, testing, stabilization, and preparation of the solution for deployment and final handover.

Important Note: Any deviation from the requirements beyond the services listed here is considered out of scope and will be treated as a "Change Request." It must be obtained separately through a formal written amendment, which may result in additional costs or modified terms.
