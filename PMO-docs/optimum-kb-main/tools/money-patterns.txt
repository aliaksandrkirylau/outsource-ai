# Money screen, shared by tools/kb-lint.mjs (the whole repo) and tools/kb-money.pl (the commit
# gate in kb-sync.sh and the pre-commit hook). One rule per line: LEVEL <tab> name <tab> regex.
# ERROR blocks a commit: a figure tied to money. WARN is printed: a figure that may be money, a
# person looks. Matching is case-insensitive.
# Before matching, link targets, bare URLs, wikilinks and inline code without spaces (Drive and chat
# IDs) are blanked, and each line is also tried joined to the next line, because PDFs and chats
# split "USD" from the figure.
# Write each regex in the subset JavaScript and Perl read alike: [0-9] not \d, explicit letter ranges
# not \w, literal Cyrillic and Arabic characters, no \u escapes.
# Known trap: inline math like "$0.5$" reads as a dollar amount. Write formulas in a $$ block or as
# plain text.
# To check a change: every line of tools/money-samples.txt must land where it says
# (perl tools/kb-money.pl --samples), and node tools/kb-lint.mjs must stay clean.
