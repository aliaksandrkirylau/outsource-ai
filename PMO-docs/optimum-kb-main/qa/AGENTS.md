# qa/

- What: QA's working area once QA joins: test plans, run evidence, checklists. Each test item points at the Requirement it verifies.
- Trust: run evidence is high for what was observed on that build and date. A criterion counts as not met until the evidence says met.
- Not for: changing a Requirement - propose the change through ingest.
- Autoload: no - only when asked.
