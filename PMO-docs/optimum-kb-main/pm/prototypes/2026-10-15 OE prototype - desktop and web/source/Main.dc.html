2. App theme - generated by Flutter from one seed colour

ColorScheme.fromSeed(seedColor: Color(0xFFED712E), dynamicSchemeVariant: DynamicSchemeVariant.fidelity).copyWith(secondaryContainer: Color(0xFFF6CD96))
"Fidelity" keeps the brand orange exact as primaryContainer; the app bar uses it (AppBarTheme(backgroundColor: primaryContainer)) with a 4 px amber #F2A743 line below, like the site header. secondaryContainer is set to the data sheet tint #F6CD96 (menu highlight, tonal buttons, "watch" chips). Buttons use the darker primary because white text on #ED712E fails contrast (3:1). Two overrides, everything else generated.
