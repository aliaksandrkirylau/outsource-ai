OES UI Kit options

Three UI kit options for the rig desktop app and the managers' web app, shown on one component gallery. Sample values are mock data.

Flutter, Material 3 standard widgets only; charts with fl_chart (MIT). No paid libraries.

Font: the screenshots show Roboto (web version); the Windows app uses Segoe UI, the Windows system font.

Sample screens and values are illustrations of the components, not agreed features.
